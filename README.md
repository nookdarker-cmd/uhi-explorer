# แผนที่ความร้อนเมือง · Urban Heat Explorer

เว็บแอปสำหรับโครงงาน YSC ศึกษาความสัมพันธ์ระหว่างสิ่งปลูกสร้างกับอุณหภูมิพื้นผิวช่วงบ่าย เทียบกรุงเทพฯ กับขอนแก่นย้อนหลัง 20 ปี และหาย่านที่ควรปรับปรุงเพื่อลดความร้อนให้ผู้อยู่อาศัย โดยใช้ข้อมูลดาวเทียมผ่าน Google Earth Engine

- **ผลการศึกษา: กรุงเทพฯ vs ขอนแก่น** เกาะความร้อนในเมือง (SUHII = อุณหภูมิเขตเมือง − ชนบทรอบ ๆ) รายปี แนวโน้มต่อ 10 ปี อาคารเพิ่ม → ร้อนขึ้น คนที่ได้รับผล และย่านที่ควรปลูกต้นไม้
- **ย่านที่ควรปรับปรุง:** ผิวร้อนมาก + คนอยู่หนาแน่น + พื้นที่สีเขียวน้อย พร้อมตารางความไวของผลต่อเกณฑ์ และพื้นที่ที่ยังปลูกต้นไม้เพิ่มได้
- **เปรียบเทียบอุณหภูมิ** ตามสัดส่วนพื้นที่สีเขียวและสิ่งปลูกสร้าง พร้อมช่วงความเชื่อมั่น 95% เลือกปีและฤดูได้ (ทั้งปี / หน้าร้อน / หน้าฝน / หน้าหนาว)
- **ย้อนหลัง 20 ปี:** อุณหภูมิรายปีพร้อมแนวโน้ม และอาคารที่เพิ่มขึ้นเทียบกับกลุ่มเทียบที่ไม่เปลี่ยนแปลง
- ส่งออกตัวเลข (CSV) และรูปกราฟ (PNG) ได้ทุกแท็บ, ลิงก์จำค่าที่เลือกไว้ (ใช้ทำ QR บนโปสเตอร์ได้)

## วิธีวิเคราะห์โดยย่อ

| ส่วน | วิธี |
|---|---|
| อุณหภูมิพื้นผิว | เฉพาะภาพช่วง 12–14 น. ที่ความคลาดเคลื่อน ≤ 2 K และต้องมีวันท้องฟ้าโปร่งอย่างน้อย 5 วันต่อฤดู/ปี |
| ต่อเนื่องข้ามดาวเทียม | ปี 2023 ขึ้นไปใช้ VIIRS ลบส่วนต่าง VIIRS − Aqua รายพิกเซลจากวันที่วัดได้ทั้งคู่ (2013–2020) และตรวจสอบกับปี 2021–2022 |
| เขตเมือง / ชนบท | เขตเมือง = urban centre ของ GHSL Degree of Urbanisation; ชนบท = ช่องชนบท 2–20 กม. รอบเมือง ไม่ใช่แหล่งน้ำ ความสูงต่างจากเมืองไม่เกิน 50 ม. |
| พื้นผิว | ประเภทที่พบบ่อยที่สุดของปีในแต่ละพิกเซล (Dynamic World) แล้วนับสัดส่วนต่อช่อง ≈1 กม. |
| พื้นที่ปลูกต้นไม้เพิ่มได้ | หญ้า พุ่มไม้ ดินเปล่า (ESA WorldCover 2021) ในย่านที่มีคนอยู่ |

## ข้อมูลที่ใช้

| ข้อมูล | แหล่ง |
|---|---|
| อุณหภูมิพื้นผิว | NASA MODIS Aqua (MYD11A1) 2003–2022, NASA VIIRS (VNP21A1D) 2023 เป็นต้นไป |
| พื้นผิว | Dynamic World V1 (Google, National Geographic Society, World Resources Institute) |
| พื้นที่ปลูกต้นไม้เพิ่มได้, แหล่งน้ำ | ESA WorldCover 2021 |
| สิ่งปลูกสร้าง, ประชากร, ระดับความเป็นเมือง | GHSL BUILT-S, POP, SMOD (European Commission JRC) |
| ความสูงของพื้นที่ | SRTM |
| ขอบเขตจังหวัด | FAO GAUL 2015 (ใช้เพื่อการศึกษา ไม่ใช่เชิงพาณิชย์) |

## ความเร็ว

บนเว็บจริง เซิร์ฟเวอร์จะสั่ง Earth Engine คำนวณชั้นข้อมูลรายปีล่วงหน้าบนกริด 30 ฟิลิปดา (≈1 กม.) เก็บไว้ใน `projects/<project>/assets/uhi_v2` (ชุดเดิม `uhi_v1` ใช้แทนชั่วคราวระหว่างรอ) ครั้งแรกใช้เวลาหลายชั่วโมง ดูความคืบหน้าได้ที่ `/api/status`

## รันบนเครื่องตัวเอง (Windows)

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
earthengine authenticate
python app.py
```

แล้วเปิด http://127.0.0.1:5000

## รันเป็นเว็บ (Render)

- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app --workers 1 --threads 4 --timeout 300`
- Environment variables:
  - `EE_SERVICE_ACCOUNT_KEY` = เนื้อหาไฟล์ JSON ของ service account ทั้งไฟล์
  - `EE_PROJECT` = Project ID ของ Google Cloud (ถ้าไม่ใส่จะใช้ค่าในโค้ด)
  - `PYTHON_VERSION` = `3.12.3`

**ห้ามอัปโหลดไฟล์ key ของ service account ขึ้น GitHub**
